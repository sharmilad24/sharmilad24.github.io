Reddit hackathon

Last Voyage

A daily escape game on Reddit where everyone plays the same sinking ship. Each board is seeded from the UTC date and checked with a breadth first search so it is always winnable. Redis enforces one scored run per day and powers streaks and a top 10 leaderboard. Everything draws on HTML5 Canvas, with sound synthesized in the browser. Open source under BSD-3-Clause, built with a teammate.

Learning project

FaceVault

A face recognition app built to understand embeddings. A pretrained FaceNet model through DeepFace turns each face into a 128 number vector, and recognition is a nearest distance lookup. The Streamlit app adds people, identifies a new photo with the distance behind each match, and plots stored faces on a 2D vector map.

  • Python
